# Images Directory

This directory contains product images, brand images, and other visual assets.

## Required Images

### Product Images
- `product-main.jpg` - Main product image (primary display)
- `product-angle-1.jpg` - Product from different angle
- `product-angle-2.jpg` - Product from different angle
- `product-angle-3.jpg` - Additional product view

### Brand Images
- `hero-background.jpg` - Hero section background image (optional, can use gradient)
- `brand-logo.png` - Company logo (if not using text logo)

### Video Thumbnails
- `video-poster.jpg` - Video thumbnail/poster image

## Image Specifications

- **Format:** JPG for photos, PNG for logos/transparent images
- **Main Product Image:** Recommended 1200x1200px minimum
- **Gallery Images:** 800x800px recommended
- **Hero Background:** 1920x1080px or larger
- **Optimization:** Compress images for web (use tools like TinyPNG, ImageOptim)
